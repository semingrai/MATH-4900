# Repo reconnaissance — one per engine (10 minutes, before you install anything)

Engine: ______________________   GitHub URL: ______________________

1. **What does the README say it is, in one sentence?**
2. **License** (look for LICENSE or the sidebar): ______ — may I run it? modify it? redistribute a copy?
3. **Last commit date / release date:** ______  Is it maintained, finished, or abandoned?
4. **Stars / forks / open issues:** ______ — what are the top three open issues about?
5. **How do you install it?** Source (clone) or Releases page (binaries)? Which one do I need?
6. **Dependencies:** (`requirements.txt`, `setup.py`, `pyproject.toml`, or a build system?) Do I have them?
7. **Where is the algorithm?** Name the file and function that embodies it: ______
8. **How do I run it?** The exact command from the README: ______
9. **How does it talk to other programs?** UCI? XBoard? Python import? Colab only?
10. **Who wrote it, and what did they write about it?** (blog post, paper, talk) — link: ______

*Copy this file into the engine's folder as `RECON.md` and fill it in. Then, and only then, follow the install recipe.*
